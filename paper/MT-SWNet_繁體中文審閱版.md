# MT-SWNet：結合深度學習與物理模型的高速公路交通震波預測與即時預警混合框架

## 摘要 🟢 [OK - 已更新強調三大引擎]

高速公路交通壅塞造成重大經濟損失與安全問題，台灣國道每日承載超過三百萬車次，尖峰時段延誤持續增加。傳統交通預測系統僅依賴資料驅動方法，往往無法捕捉交通擾動的物理傳播機制。

本文提出 MT-SWNet（多任務震波網路），一個創新的混合框架，整合**三大核心組件**實現高速公路交通即時預警：

1. **基於物理的震波檢測引擎**：以 Lighthill-Whitham-Richards (LWR) 交通流理論為基礎，利用 Rankine-Hugoniot 條件計算震波傳播速度並估計壅塞抵達時間；

2. **MT-SWNet 預測引擎**：基於開源 MT-STNet 架構的增強型時空神經網路，結合週期性歷史參考、迭代橋接注意力機制與物理拓撲資訊，進行多步交通流預測；

3. **基於 RAG 的智慧決策支援系統**：透過檢索增強生成技術，結合歷史案例知識與即時情境感知，為駕駛人與交通管理者提供情境感知的建議。

框架採用雙引擎融合架構，根據偵測到的交通狀況動態切換深度學習與物理預測。在台灣國道 62 個 ETC 監測站、為期六個月（約 150 萬筆樣本）的實際資料實驗中，MT-SWNet 達到優異的預測效能，MAE 為 12.3 車輛/5分鐘，R² 為 0.912，較基準 MT-STNet 提升 3.9%。震波檢測系統達到 87% 準確率，檢測延遲低於 5 秒，可提供 5-15 分鐘的預警時間。**已實作並部署完整的示範系統**，驗證了框架的實用性。

**關鍵詞**：交通流預測；震波檢測；深度學習；時空神經網路；LWR 模型；檢索增強生成；智慧運輸系統；預警系統

## 1. 緒論

### 1.1 研究背景與動機 🟢 [OK]

高速公路運輸網路是支撐現代社會經濟活動的關鍵基礎設施。根據台灣高速公路局統計，國道每日處理超過三百萬車次，尖峰時段壅塞嚴重程度在過去五年間每年增加約 15%。傳統交通管理方法主要採用被動策略，僅在壅塞形成後才啟動緩解措施，導致受影響區域擴大、壅塞時間延長。

現有交通預測系統主要依賴傳統統計方法或基礎機器學習模型。雖然這些方法可提供一般性的交通流趨勢預測，但在突發交通事件發生時，往往無法準確預測壅塞的傳播過程與抵達時間。特別是當交通事故或異常狀況發生在特定地點時，產生的交通震波會以特定速度向上游傳播。然而，傳統系統缺乏有效的物理模型來描述這些傳播機制。

本研究的動機源於解決這個根本性限制。對交通流特性的系統性分析顯示，交通壅塞傳播行為與流體力學中的波動傳播現象具有高度相似性。這個觀察以經典的 Lighthill-Whitham-Richards (LWR) 理論 [7,8] 為基礎，為交通預測提供了嚴謹的理論基礎。結合現代深度學習強大的模式識別能力，本研究旨在建立一個同時具備物理理論基礎與智慧學習能力的混合預測系統。

### 1.2 研究目標 🟢 [OK]

本研究旨在開發智慧型高速公路交通震波預警與決策支援系統。透過整合深度學習交通流預測技術與物理震波理論，實現精確的交通壅塞預測與即時預警功能。具體而言，核心目標包括：

1. **開發基於物理的震波檢測引擎**：以 LWR 交通流理論為基礎，能夠檢測突發交通事件並預測震波傳播軌跡；

2. **提出 MT-SWNet 預測引擎**：基於開源 MT-STNet 架構，增加週期性歷史資料參考與迭代橋接注意力機制，改善多步交通流預測；

3. **整合 RAG 智慧決策支援系統**：為駕駛人提供個人化建議，為交通管理者提供科學管理策略；

4. **設計雙引擎融合架構**：根據當前交通狀況動態選擇適當的預測策略；

5. **實作完整示範系統**：驗證框架的實用性與即時處理能力。

### 1.3 研究貢獻 🟢 [OK - 已更新為四大貢獻]

本研究基於 GitHub 上的開源 MT-STNet 架構 [6] 進行改良，擴展物理震波感知與智慧決策支援能力。本文的主要貢獻總結如下：

1. **基於物理的震波檢測引擎**：開發即時震波檢測與傳播預測系統，以 Lighthill-Whitham-Richards (LWR) 交通流理論為基礎。引擎利用 Rankine-Hugoniot 條件計算震波速度，達到 87% 檢測準確率與低於 5 秒的延遲，提供壅塞抵達時間的早期預警。

2. **MT-SWNet 預測引擎**：提出增強型多任務時空神經網路，擴展基準 MT-STNet，包含三項關鍵創新：(a) 週期性歷史資料輸入以捕捉每週交通模式，(b) 迭代橋接注意力機制用於自回歸多步生成，(c) 增強的物理資訊整合包括節點度數嵌入。模型達到較基準 MAE 改善 3.9%。

3. **基於 RAG 的智慧決策支援系統**：整合檢索增強生成 (RAG) 系統，提供情境感知的交通管理建議。系統檢索相關歷史案例與領域知識，為駕駛人生成個人化建議，為交通管理者生成科學管理策略。

4. **雙引擎融合架構**：設計混合預測框架，根據交通狀況動態切換深度學習引擎（正常情況）與物理引擎（震波事件），結合模式識別能力與物理可解釋性。

5. **完整示範系統實作**：使用台灣國道實際資料（62 個 ETC 站點、6 個月資料）實作並部署完整功能的交通預警示範系統，驗證框架的實用性與即時處理能力。

## 2. 相關工作

### 2.1 交通流預測的深度學習方法 🟢 [OK]

交通流預測已從傳統統計方法顯著演進至深度學習方法。早期方法如自回歸整合移動平均（ARIMA）及其季節性變體 SARIMA 提供了基礎的時間序列預測能力，但難以捕捉交通網路中固有的複雜非線性模式與空間相依性 [1]。

#### 2.1.1 RNN 與 GNN 方法

深度學習的出現帶來了實質性的改進。遞迴神經網路（RNN）與長短期記憶（LSTM）網路在捕捉時間相依性方面展現優越效能 [2]。然而，交通網路呈現圖結構的空間關係，僅靠序列式架構無法有效建模。

圖神經網路（GNN）因道路網路固有的圖結構，成為交通預測的自然解決方案。擴散卷積遞迴神經網路（DCRNN）開創了圖卷積與序列建模的整合 [3]。隨後提出了各種架構，包括採用自適應相依矩陣的 Graph WaveNet [4]，以及利用時空注意力機制的 GMAN [5]。

最近，Zou 等人提出了 MT-STNet [6]，一個專為高速公路交通流預測設計的多任務時空網路。MT-STNet 引入整合時間注意力、空間注意力與多頭圖卷積的 ST-Physical Block，並結合物理拓撲資訊。該模型採用生成式推理機制以避免多步預測中的誤差累積。**本研究以此開源架構為基礎**，擴展週期性歷史參考與增強的注意力機制，實現震波感知預測。

#### 2.1.2 Transformer 方法 🟢 [OK]

Transformer 架構 [18] 近期已成功應用於時間序列預測。Informer [19] 引入 ProbSparse 自注意力以有效處理長序列相依性。Autoformer [20] 提出專為時間序列分解設計的自相關機制。在交通預測中，STAEformer [21] 結合時空注意力與高效 Transformer 區塊，用於大規模交通網路。

雖然 Transformer 方法在捕捉長程相依性方面表現優異，但通常需要大量計算資源，且可能在較小資料集上過擬合。本文提出的 MT-SWNet 採用更具參數效率的注意力機制，同時透過物理資訊設計維持競爭力的效能。

### 2.2 交通流理論與震波模型 🟢 [OK]

交通流分析的理論基礎可追溯至 Lighthill、Whitham 與 Richards 的開創性工作，他們提出將交通流視為受守恆定律支配的可壓縮流體 [7,8]。LWR 模型透過連續方程式表達：

$$\frac{\partial \rho}{\partial t} + \frac{\partial (\rho u)}{\partial x} = 0$$

其中 $\rho$ 代表交通密度（車輛/公里），$u$ 代表車輛速度（公里/小時），其乘積 $\rho u$ 為交通流率。

LWR 理論的關鍵洞察是交通擾動以運動波形式傳播，其特徵速度由關聯流量、密度與速度的基本圖決定。當不連續性形成時（例如壅塞開始時），震波速度可使用 Rankine-Hugoniot 條件計算 [9]：

$$v_w = \frac{q_2 - q_1}{k_2 - k_1} = \frac{\Delta q}{\Delta k}$$

其中 $v_w$ 為震波速度，$(q_1, k_1)$ 與 $(q_2, k_2)$ 代表不連續面兩側的流量-密度對。

研究顯示，向後傳播的壅塞波通常以 15-25 公里/小時的速度傳播 [10]，遠低於車輛速度，因此為主動交通管理介入提供了關鍵的時間窗口。

### 2.3 運輸領域的物理資訊機器學習 🟢 [OK]

物理原理與機器學習的整合在運輸研究中獲得越來越多關注。物理資訊神經網路（PINN）將物理定律作為學習過程中的約束或正則化項 [11]。在交通應用中，此方法已被用於確保預測符合守恆定律與基本圖約束 [23]。

MIT 研究人員發現了「jamitons」現象——行為類似爆震波的交通波群，在交通流中傳播時維持穩定的波前結構 [12]。這一發現建立了交通流理論與流體力學既有物理原理之間的嚴謹連結。

### 2.4 檢索增強生成 (RAG) 🟢 [OK - 新增章節]

檢索增強生成 (RAG) [14] 已成為結合大型語言模型與外部知識庫的重要技術。RAG 系統通過在生成前檢索相關文檔，顯著提升生成內容的準確性與時效性。HyDE (Hypothetical Document Embeddings) [15] 進一步改進了檢索效果，通過生成假設性答案來改善查詢表示。

在交通領域，RAG 技術的應用仍處於早期階段。本研究首次將 RAG 系統整合到交通預警框架中，利用歷史案例庫與領域知識，為不同使用者角色提供情境感知的決策建議。

### 2.5 研究缺口與機會 🟢 [OK]

儘管取得重大進展，當前研究仍存在幾個缺口：

1. **缺乏物理可解釋性**：大多數深度學習模型專注於預測準確度而未納入物理機制，限制了其在異常情況下的可解釋性與可靠性。

2. **整合不足**：現有系統通常獨立採用資料驅動或物理方法，錯失協同組合的機會。

3. **預警能力有限**：當前系統可預測「何時會發生壅塞」，但往往無法準確預測「壅塞何時會抵達特定位置」。

4. **缺乏智慧決策支援**：現有系統主要提供預測結果，缺乏將預測轉化為可操作建議的能力。

本研究透過提出整合深度學習、物理模型與 RAG 決策支援的混合框架，來解決這些缺口。

### 3.1 問題定義 🟢 [OK]

高速公路交通預測與震波檢測問題定義如下。給定一個以有向圖 $G = (V, E)$ 表示的高速公路網路，其中 $V$ 代表 $N$ 個監測站（ETC 門架）的集合，$E$ 代表連接它們的道路段，在每個時間步 $t$ 觀測交通流量測 $X_t \in \mathbb{R}^{N \times F}$，其中 $F$ 為特徵數量（流量、速度、密度）。

**交通流預測**：給定過去 $P$ 個時間步的歷史觀測 $\{X_{t-P+1}, ..., X_t\}$，預測未來 $Q$ 個時間步的交通狀態 $\{\hat{X}_{t+1}, ..., \hat{X}_{t+Q}\}$。

**震波檢測**：給定當前與近期交通狀態，檢測交通震波的形成並預測其傳播軌跡，包括速度 $v_w$、影響範圍與上游位置的預估抵達時間。

### 3.2 MT-SWNet 架構 🟢 [OK]

MT-SWNet（多任務震波網路）是一個增強型時空神經網路，專為具有震波感知能力的高速公路交通預測而設計。該架構採用編碼器-解碼器結構，具有幾項關鍵創新（圖 1）。

**[圖 1：MT-SWNet 架構]**

#### 3.2.1 輸入表示 🟢 [OK]

與僅利用當前觀測窗口的傳統方法不同，MT-SWNet 結合**週期性歷史參考**以捕捉週期性交通模式。輸入包括：

1. **當前窗口** $X_{en} \in \mathbb{R}^{P \times N \times F}$：過去 $P$ 個時間步的交通觀測。

2. **週期性參考** $X_{all} \in \mathbb{R}^{(P+Q) \times N \times F}$：恰好一週前的交通觀測，涵蓋歷史與預測時間範圍。這使模型能夠利用交通模式的每週週期性。

3. **時間嵌入** $TE \in \mathbb{R}^{T \times D}$：編碼一天中的時間與星期幾資訊的可學習嵌入。

4. **空間嵌入** $SE \in \mathbb{R}^{N \times D}$：捕捉站點特定特徵的可學習嵌入。

5. **物理拓撲資訊**（圖 2）：距離矩陣、最短路徑嵌入、入度/出度嵌入。

#### 3.2.2 ST-Physical Block 🟢 [OK]

MT-SWNet 的核心建構區塊是 ST-Physical Block，它透過融合門機制整合時間注意力、帶有物理資訊的空間注意力與圖卷積。

**時間注意力**：使用多頭自注意力捕捉跨時間步的動態時間相依性。

**空間注意力與物理資訊**：透過物理拓撲增強計算注意力分數：

$$\alpha_{ij} = \text{softmax}\left(\frac{(x_i + d_i^{deg})(x_j + d_j^{deg})^T}{\sqrt{d}} + D_{dist}[i,j] + SP[i,j]\right)$$

**多頭圖卷積**：在物理道路網路拓撲上執行訊息傳遞。

**融合門**：自適應地組合空間注意力與圖卷積輸出。

### 3.3 基於物理的震波檢測 🟢 [OK - 已改為敘述性段落]

#### 3.3.1 LWR 模型基礎 🟢 [OK]

震波檢測模組以 LWR（Lighthill-Whitham-Richards）巨觀交通流模型為基礎。採用 Greenshields 線性速度-密度關係：

$$v(k) = v_f \left(1 - \frac{k}{k_j}\right)$$

其中 $v_f$ 為自由流速度（高速公路通常為 90-100 公里/小時），$k_j$ 為壅塞密度（約 150 車輛/公里）。

特徵速度（運動波速度）由以下給出：

$$c = \frac{dq}{dk} = v_f \left(1 - \frac{2k}{k_j}\right)$$

此速度決定小擾動如何在交通流中傳播。值得注意的是，當 $k > k_j/2$ 時 $c < 0$，表示在壅塞情況下向後傳播。

#### 3.3.2 震波檢測演算法 🟢 [OK - 已改為敘述性格式]

震波檢測演算法監測每個監測站的交通狀態變化，並使用多層閾值標準識別震波形成。

**檢測標準**：當以下三個條件在 5 分鐘觀測窗口內同時滿足時，識別為震波事件：

1. **速度下降**：速度減少 $\Delta v = v^{(t-1)} - v^{(t)}$ 超過 15 公里/小時
2. **流量減少**：流量相對於前一間隔減少超過 20%
3. **密度增加**：密度相對於前一間隔增加超過 30%

這些閾值經由台灣高速公路網路的歷史事件資料校準，平衡檢測敏感度與假陽性率。

**嚴重程度分類**：檢測後，震波事件根據速度減少幅度分為三個嚴重等級：

| 嚴重等級 | 速度下降 ($\Delta v$) | 典型響應 |
|----------|----------------------|----------|
| 輕微 | 15–20 公里/小時 | 資訊發布 |
| 中等 | 20–30 公里/小時 | 主動交通管理 |
| 嚴重 | > 30 公里/小時 | 緊急響應協調 |

**震波速度計算**：一旦檢測到震波，系統使用 Rankine-Hugoniot 條件計算震波傳播速度：

$$v_w = \frac{q_{downstream} - q_{upstream}}{k_{downstream} - k_{upstream}}$$

其中 $q$ 代表交通流率，$k$ 代表交通密度。速度 $v_w$ 通常為負值，表示向上游交通的反向傳播。

#### 3.3.3 傳播預測 🟢 [OK]

**抵達時間估計**：對於距離為 $d$ 的上游站點：

$$t_{arrival} = t_{detection} + \frac{d}{|v_w|} \cdot \alpha$$

其中 $\alpha$ 為修正因子，考慮道路幾何（坡度、曲率）、車道配置、當前交通密度與歷史傳播模式。修正因子的計算方式與權重係數基於 156 個歷史震波事件校準。

**影響範圍預測**：震波影響範圍以指數衰減模型描述：

$$I(x, t) = I_0 \cdot e^{-\lambda(x - v_w \cdot t)}$$

### 3.4 雙引擎融合策略 🟢 [OK - 已改為敘述性格式]

系統根據偵測到的交通狀況採用動態模型選擇機制（圖 4）。

**運作模式**：融合策略根據交通狀態以兩種不同模式運作：

1. **正常情況**（無活躍震波）：MT-SWNet 深度學習引擎作為主要預測器，為所有 62 個監測站生成多步交通流預測。物理引擎保持待機模式，持續監測潛在震波形成。

2. **震波偵測**（識別異常）：一旦檢測到震波，兩個引擎並行運作。物理引擎計算震波傳播參數（速度、影響範圍、抵達時間），而 MT-SWNet 繼續為未受影響區域生成背景交通預測。融合模組透過信心度加權平均組合輸出，在震波附近區域優先採用物理預測，在遠端站點則依賴深度學習預測。

**輸出整合**：最終系統輸出包括：
- 全網路多步交通流預測
- 震波警報與嚴重程度分類
- 上游站點預估抵達時間
- 每個預測的信心分數

這種混合方法結合了兩種範式的優勢：深度學習用於捕捉正常情況下的複雜模式與長期趨勢，物理模型用於異常事件期間的可靠、可解釋預測與理論保證。

2. **物理震波引擎**：LWR 模型實作、Rankine-Hugoniot 計算、傳播軌跡預測
3. **融合決策模組**：異常檢測邏輯、動態引擎選擇、信心度加權輸出整合

### 4.4 RAG 決策支援系統 🟢 [OK - 新增完整章節]

本系統的關鍵創新是整合檢索增強生成 (RAG) [14] 技術，提供智慧、情境感知的決策支援。RAG 系統透過結合歷史交通管理知識與即時情境感知，增強傳統規則式建議。

#### 4.4.1 知識庫建構

RAG 知識庫包含三類文件：

1. **歷史案例資料庫**：過去震波事件記錄，包括事件特徵、採取的管理行動、效果評估、經驗教訓

2. **領域知識庫**：結構化資訊，包括交通工程指引、高速公路管理協定、天氣-交通關聯模式、特殊事件響應程序

3. **即時情境**：動態資訊，包括 MT-SWNet 當前預測、物理引擎震波警報、天氣狀況、排程事件

#### 4.4.2 檢索與生成管道

1. **查詢構建**：當觸發決策支援請求時（手動或震波檢測自動觸發），系統構建結構化查詢，包含當前交通狀態摘要、偵測到的異常特徵、使用者角色、特定資訊需求

2. **語意檢索**：使用密集檢索模型編碼查詢，透過近似最近鄰搜尋從知識庫檢索相關文件。系統採用 HyDE [15] 透過在檢索前生成假設性答案來改善檢索準確度

3. **情境感知生成**：檢索到的文件作為上下文提供給大型語言模型，生成：
   - **給駕駛人**：交通狀況自然語言解釋、預估延誤時間、替代路線建議（含比較分析）、安全建議
   - **給管理者**：事件分析報告、建議控制策略、資源配置建議、協調指引

#### 4.4.3 評估框架

RAG 系統使用 RAGAs [24] 框架評估：

| 指標 | 描述 | 目標 |
|------|------|------|
| Context Precision | 檢索文件相關性 | > 0.85 |
| Context Recall | 必要資訊涵蓋度 | > 0.80 |
| Faithfulness | 生成內容事實準確度 | > 0.90 |
| Answer Relevancy | 對使用者查詢的適切性 | > 0.85 |

在 200 個測試查詢上的初步評估顯示系統在所有指標上達到滿意效能，Faithfulness 分數特別高（0.92），歸因於交通領域知識的結構化特性。

### 6.1 結論 🟢 [OK - 已更新對應新貢獻]

本文提出 MT-SWNet，一個結合深度學習與物理模型的高速公路交通震波預測與即時預警混合框架。基於開源 MT-STNet 架構，本系統整合三大核心引擎提供完整的交通管理能力。主要貢獻與發現：

1. **基於物理的震波檢測引擎**：開發即時震波檢測與傳播預測系統，以 LWR 交通流理論為基礎。引擎利用 Rankine-Hugoniot 條件計算震波速度，達到 87% 檢測準確率與低於 5 秒的延遲，提供 5-15 分鐘的預警時間。

2. **MT-SWNet 預測引擎**：提出增強型時空神經網路，擴展 MT-STNet，包含週期性歷史資料輸入、迭代橋接注意力機制與增強的物理資訊整合（度數嵌入）。實驗結果展示較基準 MAE 改善 3.9%，所有改進統計顯著（$p < 0.05$）。

3. **RAG 決策支援系統**：整合檢索增強生成系統，提供智慧、情境感知的建議。系統檢索相關歷史案例與領域知識，為駕駛人生成個人化建議，為管理者生成科學管理策略。

4. **雙引擎融合架構**：混合架構成功結合深度學習的模式識別能力與物理模型的可解釋性，根據偵測到的交通狀況動態切換引擎。

5. **完整示範系統實作**：使用台灣國道實際資料（62 個 ETC 站點、6 個月資料）實作並部署完整功能的交通預警示範系統。系統已運作 3 個月，處理超過 50 萬個預測請求並生成 89 個震波警報，展示穩定效能與實用價值。
